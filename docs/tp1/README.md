# TP1 — Baseline Linux hardening

TP1 built the base Arch Linux VM and introduced hardening in four areas:

1. filesystem layout and mount restrictions;
2. administrative authentication and sudo logging;
3. encrypted application storage with removable key material;
4. bootloader protection.

See [implementation.md](implementation.md) for the technical path and [../../docs/validation.md](../validation.md) for the evidence summary.
