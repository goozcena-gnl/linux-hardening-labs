# v1.0.0 — TP1 & TP2 Linux Hardening Labs

Initial public release of the Linux Hardening Labs portfolio repository.

## Highlights

### TP1 — baseline hardening

- hardened Arch Linux filesystem layout;
- LUKS2 encrypted application storage;
- LVM-backed `/data`;
- removable/simulated `LABEL=KEY` device;
- degraded boot and encrypted-volume recovery script;
- root/rescue SSH restrictions;
- TOTP authentication;
- dedicated sudo logging;
- GRUB protection.

### TP2 — extended hardening

- targeted kernel/sysctl validation;
- irreversible module-loading lock after required modules are loaded;
- PAM password quality and root enforcement;
- account lockout with faillock;
- time-based PAM restriction;
- SSH public key followed by OTP;
- `pam_exec` SSH attempt logging;
- local administrator sudo via OTP;
- auditd EXECVE rules;
- umask `0077`;
- read-only `/boot`;
- permission-change monitoring;
- read-only audit evidence collector.

## Engineering quality

- Markdown-first documentation;
- explicit distinction between requirement, configuration, runtime state and functional evidence;
- known gaps preserved instead of converted into false PASS results;
- Bash syntax validation;
- ShellCheck;
- Markdown lint;
- Gitleaks secret scanning;
- Dependabot for GitHub Actions;
- MIT license and third-party notice.

## Known evidence limitations

- auditd login/logout event types were not demonstrated;
- no out-of-window `pam_time` denial was demonstrated;
- sudo OTP was demonstrated for `localadm`, not generalized to `rescue`;
- kernel comparison was demonstrated point-in-time rather than as continuous monitoring;
- no independent ANSSI compliance claim is made.

## Publication scope

Course PDFs, intermediate reports, raw audit archives, MFA seeds, LUKS key material, private keys and password hashes are intentionally excluded from the public repository.
