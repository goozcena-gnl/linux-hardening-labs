# TP1 audit handling

TP1 was also evaluated from a captured VM state, but the raw audit archive is intentionally not versioned here.

Public repository policy:

- keep the final engineering conclusions in Markdown;
- keep reproducible, non-secret scripts where available;
- do not commit raw host archives by default;
- never commit `data.key`, MFA seeds, password hashes or private SSH keys;
- treat screenshots and reports as supporting evidence, not the source of truth.

The TP1 implementation and verification results are summarized in [docs/tp1/implementation.md](../../docs/tp1/implementation.md) and [docs/validation.md](../../docs/validation.md).
